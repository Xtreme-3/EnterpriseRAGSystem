## 答案原文（截断 300 字）

**1. 供应商准入需要满足哪些基本资质？**（资质表）
> 根据《全球优选_供应商管理制度》2.1 节，供应商准入需满足以下基本资质门槛：  1.  **营业执照**：注册资金 ≥100 万人民币，经营范围涵盖供货品类； 2.  **生产许可**：涉及食品接触材料须提供《全国工业产品生产许可证》； 3.  **体系认证**：ISO 9001 为硬性要求，皮具类须有 Leather Working Group 认证或等效力； 4.  **环保合规**：排污许可证或环保备案回执，不得在环保黑名单内； 5.  **出口资质**：能开具增值税专用发票，具备出口退税备案； 6.  **社会责任**：通过 SMETA/BSCI/SA8000 之一的社会责任审核。

**2. 皮具类的五金件有什么标准？**（4.2 小节）
> 根据《全球优选_供应商管理制度》4.2 节，皮具类五金件的标准如下：  1.  **品牌指定**：拉链品牌指定为 YKK 或 SBS，须提供品牌授权证明 [4]。 2.  **电镀厚度**：铜底镀镍 ≥5μm + 镀金/镀铬 ≥0.1μm [4]。 3.  **磁扣吸力**：单颗磁扣闭合力 ≥3N [4]。 4.  **耐腐蚀测试**：所有五金件须能通过 48 小时中性盐雾测试（ISO 9227） [4]。  此外，根据《全球优选_产品手册》2.3 节关于皮具质检标准的规定，五金件还需满足：盐雾测试 ≥48小时无锈斑，拉链开合 5000次无卡顿 [3]。

**3. 美国站的退货窗口是多少天？**（退换货窗口表）
> 美国站的退货窗口为 **30 天**。  根据《全球优选_跨境售后政策.pdf》第二章“各国市场退换货窗口”表格显示，美国市场的法定退货期因州而异（多数无强制），但公司承诺执行 **30 天无理由退货** [1]。

**8. 皮具出厂前要做哪些质检？**（2.3 质检标准）
> 根据《全球优选_产品手册.pdf》2.3 节，皮具出厂前的质检标准主要包含以下五个方面：  1.  **皮面**：无明显虫疤、血筋、松面。允许≤2处直径小于3mm的自然纹理差异 [1]。 2.  **五金**：盐雾测试 ≥48小时无锈斑，拉链开合 5000次无卡顿 [1]。 3.  **缝线**：线迹平直，每英寸 6-7 针，断线接头≤1处/件 [1]。 4.  **色牢度**：干擦 ≥4级，湿擦 ≥3.5级（ISO 105-X12） [1]。 5.  **气味**：不得有刺鼻化学气味（甲醛 ≤75mg/kg，符合 REACH） [1]。

> 根据《全球优选_供应商管理制度.pdf》3.3 节“一票否决项”，以下五种情况发生，将直接终止合作且不予结算在途货款 [1]：  1. **恶意偷工减料**：材质与合同约定不符（如合同要求头层牛皮，实际使用二层或人造革）； 2. **擅自转包**：未经书面同意将订单转包第三方生产； 3. **商业贿赂**：向公司员工行贿获取订单或质检放行； 4. **严重安全事故**：因供应商原因导致终端消费者人身伤害； 5. **数据造假**：伪造检测报告、篡改生产记录。
