## 第一章 总则

### 1.1 目的

规范供应商准入、考核、淘汰全流程，确保供应链质量稳定、成本可控、交付准时。

### 1.2 适用范围

本制度适用于 GLOBEST 品牌旗下所有原材料供应商、OEM/ODM 代工厂、包材辅料供应商。物流服务商另行适用《物流服务商管理办法》，不在本制度范围内。

### 1.3 核心原则

- **质量优先**：质量评分占供应商总评分 50%，安全类问题适用一票否决制。
- **阳光采购**：所有供应商须签署《反商业贿赂承诺书》，采购人员不得接受供应商任何形式的馈赠。
- **长期合作**：年度评分前 20% 的供应商享受优先排单与结算优惠。

## 第二章 供应商准入

### 2.1 基本资质门槛

| 资质项 | 要求 |
|---|---|
| 营业执照 | 注册资金不少于 100 万人民币，经营范围涵盖供货品类 |
| 生产许可 | 涉及食品接触材料须提供《全国工业产品生产许可证》 |
| 体系认证 | ISO 9001 为硬性要求，皮具类须有 Leather Working Group 认证或等效证明 |
| 环保合规 | 排污许可证或环保备案回执，不得在环保黑名单内 |
| 出口资质 | 能开具增值税专用发票，具备出口退税备案 |
| 社会责任 | 通过 SMETA、BSCI、SA8000 之一的社会责任审核 |

### 2.2 准入评审流程

1. **资质初审**（采购部，3 个工作日）：核对资质文件完整性。
2. **现场验厂**（品控与采购联合，5 个工作日）：按《供应商验厂检查表》逐项打分，低于 70 分直接淘汰。
3. **打样确认**（品控与设计，7 个工作日）：提供三次打样机会，三次均不合格则淘汰。
4. **小批量试产**（300 至 500 件，14 个工作日）：检验批次合格率须不低于 98%。
5. **纳入合格供应商名录**：系统录入，分配供应商编码。

### 2.3 供应商编码规则

```
SUP-{品类}-{年份}-{序号}
品类: LTH(皮具), BTL(杯具), HAT(帽饰), PKG(包材)
示例: SUP-LTH-2026-003  表示 2026 年第 3 家皮具供应商
```

## 第三章 绩效考核

### 3.1 考核维度与权重

| 维度 | 权重 | 考核指标 |
|---|---|---|
| 质量 Q | 50% | 批次合格率、客户投诉率、客诉关闭时效 |
| 交付 D | 25% | 准时交付率、紧急订单响应速度 |
| 成本 C | 15% | 报价竞争力、降价配合度 |
| 配合 S | 10% | 问题改善时效、新品开发响应 |

### 3.2 评分等级与处理

| 等级 | 分数 | 处理措施 |
|---|---|---|
| A 级（优秀） | 不低于 90 | 优先排单，账期缩短至 T+15 |
| B 级（良好） | 75 至 89 | 正常合作，T+30 账期 |
| C 级（待改进） | 60 至 74 | 减单 30%，限期 60 天改善；连续两季度 C 级降为 D 级 |
| D 级（淘汰） | 低于 60 | 立即停止新单，3 个月内完成库存清理后移出合格名录 |

### 3.3 一票否决项

发生以下情况，直接终止合作且不予结算在途货款：

1. **恶意偷工减料**：材质与合同约定不符（如合同要求头层牛皮，实际使用二层皮或人造革）。
2. **擅自转包**：未经书面同意将订单转包第三方生产。
3. **商业贿赂**：向公司员工行贿以获取订单或质检放行。
4. **严重安全事故**：因供应商原因导致终端消费者人身伤害。
5. **数据造假**：伪造检测报告、篡改生产记录。

## 第四章 皮具类特殊要求

### 4.1 皮革采购标准

| 皮料类型 | 分级标准 | 允许瑕疵 |
|---|---|---|
| 头层牛皮 | 全粒面，厚度 1.2-1.6mm | 背部主裁面无明显瑕疵，边腹允许不超过 1 处直径 5mm 伤痕 |
| 小羊皮 | 全粒面，厚度 0.8-1.0mm | 无明显血筋；允许不超过 2 处轻微色斑 |
| 疯马皮 | 油蜡处理，厚度 1.4-1.8mm | 风格化的自然纹理不属于瑕疵 |
| 二层牛皮 | 覆膜或 PU 涂饰 | 覆膜无气泡、剥离强度不低于 3N/cm |

### 4.2 五金件标准

- 拉链品牌指定 YKK 或 SBS，须提供品牌授权证明。
- 电镀厚度：铜底镀镍不少于 5μm，外加镀金或镀铬不少于 0.1μm。
- 磁扣吸力：单颗磁扣闭合力不低于 3N。
- 所有五金件须能通过 48 小时中性盐雾测试（依据 ISO 9227）。

## 第五章 杯具类特殊要求

### 5.1 不锈钢材质验证

每批次入仓须附带：

1. 材质光谱分析报告（确认 304 或 316 牌号）。
2. 食品接触材料迁移量检测（依据 GB 4806.9）。
3. 如销往欧盟，须提供 EC 1935/2004 符合性声明。

### 5.2 真空保温效能测试

- **抽样比例**：每批次 2%，且不低于 10 个。
- **测试条件**：注入 95°C±1°C 热水，环境温度 20°C±2°C。
- **判定标准**：6 小时后温度不低于 55°C 为合格（316 不锈钢）。
