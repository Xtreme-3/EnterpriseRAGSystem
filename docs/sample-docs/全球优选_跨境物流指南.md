# 全球优选 · 跨境物流操作指南

> 文件编号: SOP-LOG-2026-003 | 版本: v2.2 | 更新: 2026-06-15
> 编制: 物流部 | 适用范围: 深圳总仓、各海外仓

## 一、发货流程总览

```
订单抓取 (每小时) → 审单 (异常拦截) → 配货 (WMS波次) → 复核称重 → 贴标出库 → 干线揽收 → 清关 → 尾程派送 → 签收
```

---

## 二、订单处理规则

### 2.1 审单自动拦截条件

| 拦截类型 | 触发条件 | 处理方式 |
|---|---|---|
| 地址异常 | 地址不完整、邮编与城市不匹配、疑似 PO Box（部分线路不支持） | 转人工核实 |
| 金额异常 | 单品数量 >50 件 或 订单金额 >$2000 | 风控审核 |
| 重复订单 | 同一地址+同一 SKU 2 小时内下单 >3 次 | 合并或确认 |
| 高风险国家 | 发往 OFAC 制裁国家（伊朗、朝鲜、叙利亚等） | 自动取消+退款 |
| 电话缺失 | 尾程需电话通知的线路缺少电话号 | 转人工补充 |

### 2.2 分仓规则

| 条件 | 发货仓 | 优先级 |
|---|---|---|
| 收货地址在美国西部 (CA/OR/WA/NV/AZ) | 洛杉矶海外仓 | 1 |
| 收货地址在美国其他州，库存有货 | 洛杉矶海外仓 | 2 |
| 洛杉矶断货但深圳有库存 | 深圳总仓（快线） | 3 |
| 收货地址在欧盟 | 汉堡海外仓 | 1 |
| 汉堡断货 | 深圳总仓 → 欧盟快线 | 2 |
| 收货地址在日本 | 大阪海外仓 | 1 |

### 2.3 截单时间

| 仓 | 截单时间（当地时间） | 当日出库 |
|---|---|---|
| 深圳总仓 | 17:00 CST | 17:00 前付款订单 |
| 洛杉矶仓 | 15:00 PST | 15:00 前推送订单 |
| 汉堡仓 | 14:00 CET | 14:00 前推送订单 |
| 大阪仓 | 16:00 JST | 16:00 前推送订单 |

## 三、包装规范

### 3.1 皮具类包装

| 步骤 | 要求 |
|---|---|
| 1. 内填充 | 包内塞入拷贝纸或无纺布填充物，保持包型 |
| 2. 防潮 | 套入 PE 自封袋，内置一包硅胶干燥剂 (5g) |
| 3. 防刮 | 五金件单独包裹拷贝纸，拉链头套 EPE 保护套 |
| 4. 外箱 | K3K 瓦楞纸箱，空隙用气泡膜填充，摇晃测试无位移 |
| 5. 标识 | 外箱贴"防潮/怕压"标识，单件重量 >3kg 标注重量 |

### 3.2 杯具类包装

| 步骤 | 要求 |
|---|---|
| 1. 杯体 | 独立 PE 袋包裹，杯盖与杯体分离包装 |
| 2. 缓冲 | 定制珍珠棉（EPE）托盒，上下卡位固定 |
| 3. 外盒 | 彩色白卡纸天地盒 + 外层 K3K 运输箱 |
| 4. 抽检 | 每 500 个抽 1 个做跌落测试（1.2m 六面一角，无破损无凹陷） |

### 3.3 帽饰类包装

| 步骤 | 要求 |
|---|---|
| 1. 帽型保持 | 内置帽撑或填充纸团保持帽型 |
| 2. 防压 | 放入硬质天地盒，严禁使用快递袋直接装帽 |
| 3. 外层 | 快递防水袋 + 内层纸盒双重保护 |

### 4.2 商业发票 (Commercial Invoice) 规范

- **申报价值**: 按实际成交价申报（非成本价），虚低申报将导致海关扣货和罚款
- **品名描述**: 必须具体，不得写 "Gift" / "Sample" / "Accessories"
  - ✓ "Leather Briefcase, Cowhide" / "Stainless Steel Vacuum Flask 480ml"
  - ✗ "Bag" / "Cup" / "Daily Goods"
- **原产地**: 所有产品标注 "Made in China"
- **EORI 号码**（欧盟）: 发票须含进口方 EORI 号（Economic Operators Registration and Identification）

### 4.3 欧盟特殊合规

| 法规 | 对产品的影响 | 我们的应对 |
|---|---|---|
| REACH | 限制皮革中六价铬 ≤3mg/kg | 每批次供应商须提供 REACH 检测报告 |
| 德国包装法 VerpackG | 所有包装须注册 LUCID 回收 | 已注册，注册号: DE1234567890123 |
| 法国 Triman 标识 | 可回收包装须印 Triman 标志 | 2026 Q3 起更新包材印刷 |
| 欧盟 GPSR | 2024年12月起需指定欧盟授权代表 | 已委托 Eurofins 作为授权代表 |
| CE 标识 | 杯具有电子部件（测温杯）须 CE 认证 | HY-TH004 已取得 CE |

## 五、异常处理

### 5.1 物流异常分类

| 异常类型 | 响应时效 | 处理方案 |
|---|---|---|
| 包裹丢失 | 承运商确认为丢失后 24h 内 | 按货值全额赔付客户 → 向承运商索赔 |
| 包裹破损 | 客户提供开箱照片 24h 内 | 补发或退款（破损严重），外包装完整但内物损毁由我方承担 |
| 海关扣货 | 收到海关通知 4h 内 | 提供补充文件；如因申报原因扣货，物流负责人承担直接责任 |
| 地址错误退回 | 退回入仓 48h 内 | 联系客户确认地址，产生额外运费由客户承担（首次免运费补给） |
| 虚假签收 | 客户反馈未收到 2h 内 | 提供 POD 签收凭证+GPS 坐标；确认为虚假签收则补发并投诉承运商 |
| 旺季爆仓 | 实时监控 | 启动备用承运商，邮件批量通知客户时效延迟 |

### 5.2 承运商绩效

| 承运商 | 线路 | 准时率 KPI | 破损率上限 | 当前表现 |
|---|---|---|---|---|
| 云途 | 中美线 | ≥95% | ≤0.5% | 96.2%/0.3% ✅ |
| 燕文 | 中美线 | ≥93% | ≤0.8% | 93.5%/0.7% ✅ |
| 4PX | 中欧线 | ≥94% | ≤0.5% | 92.1%/0.6% ⚠️ 需约谈 |
| DHL eCommerce | 中美东线 | ≥97% | ≤0.3% | 97.8%/0.2% ✅ |
| 佐川急便 | 中日线 | ≥98% | ≤0.2% | 98.5%/0.1% ✅ |

> ⚠️ 4PX 连续两个月准时率低于 94%，物流部须于本月内提交整改方案或切换承运商。

## 六、库存预警规则

| 预警等级 | 触发条件 | 操作 |
|---|---|---|
| 黄 (关注) | 库存 < 3 周日均销量 | 通知采购备货 |
| 橙 (补货) | 库存 < 2 周日均销量 | 48h 内创建采购单 |
| 红 (紧急) | 库存 < 1 周日均销量 | 启动空运补货（不计成本），同步官网标注"低库存" |
