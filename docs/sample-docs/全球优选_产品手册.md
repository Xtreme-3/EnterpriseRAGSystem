### 2.3 皮具质检标准

- **皮面**: 无明显虫疤、血筋、松面。允许≤2处直径小于3mm的自然纹理差异
- **五金**: 盐雾测试 ≥48小时无锈斑，拉链开合 5000次无卡顿
- **缝线**: 线迹平直，每英寸 6-7 针，断线接头≤1处/件
- **色牢度**: 干擦 ≥4级，湿擦 ≥3.5级（ISO 105-X12）
- **气味**: 不得有刺鼻化学气味（甲醛 ≤75mg/kg，符合 REACH）
