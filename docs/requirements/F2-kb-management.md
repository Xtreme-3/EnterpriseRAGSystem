# 需求卡片：F2-知识库管理页

## 一句话
实现知识库列表页，支持创建、列表展示、删除，带顶部导航栏布局。

## 子块

| 子块 | 功能 | 说明 |
|------|------|------|
| F2-1 | DefaultLayout | 顶部导航栏：系统名 + 用户信息 + 退出登录 |
| F2-2 | 知识库列表页 | `/kbs` — 卡片网格展示所有知识库 |
| F2-3 | 创建知识库 | 对话框输入名称+描述 → `POST /api/kbs` |
| F2-4 | 删除知识库 | 二次确认 → `DELETE /api/kbs/{id}` |

## 输入 / 输出

- 列表页：进入 `/kbs` → `GET /api/kbs` → 卡片展示（名称/描述/文档数/创建时间）
- 创建：点击"新建知识库" → 弹窗填 name + description → `POST /api/kbs` → 刷新列表
- 删除：点击删除按钮 → 确认框 → `DELETE /api/kbs/{id}` → 刷新列表
- 空状态：无知识库时显示引导文字

## 验收标准（可测试）

- [ ] `/kbs` 页展示当前用户的知识库列表
- [ ] 点击"新建知识库"弹出对话框，填写名称后创建成功
- [ ] 删除知识库需要二次确认
- [ ] 空列表时显示"暂无知识库"
- [ ] 顶部导航栏显示用户名和退出按钮
- [ ] 退出登录回到 `/login`
- [ ] TypeScript 类型检查通过
- [ ] 后端 55 个测试仍然通过

## 依赖

- 前置：F1（前端脚手架 + 路由守卫），B3（知识库 CRUD API）
- 技术栈：Vue3 + Element Plus + axios

## 不做什么（边界，防止范围蔓延）

- 不做知识库详情/编辑（V1 只做 CRUD 基础）
- 不做分页（V1 知识库数量通常不大）
- 不做文档管理（F3）
- 不做表格/列表视图切换
