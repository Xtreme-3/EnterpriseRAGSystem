# 需求卡片：F4-对话页（流式问答 + 溯源引用）

## 一句话
进入知识库后可对话提问，SSE 流式展示答案，答案下方展示引用来源（文档名/内容/相似度）。

## 子块

| 子块 | 功能 | 说明 |
|------|------|------|
| F4-1 | 对话界面 | `/kbs/:kbId/chat` — 聊天气泡布局 + 输入框 |
| F4-2 | SSE 流式渲染 | token 事件逐字追加，末尾 sources + [DONE] |
| F4-3 | 溯源引用展示 | 每条来源：filename / 内容片段 / 相似度 |
| F4-4 | 入口链接 | KB 列表卡片 + 文档列表页 → "开始对话" |

## 输入 / 输出

- 输入：问题文本 → `POST /api/kbs/{id}/ask/stream` (SSE)
- 流式输出：token → 逐字渲染；sources → 答案下方折叠面板；[DONE] → 结束
- 多轮对话：V1 不做（无历史上下文），仅前端保留对话记录展示

## 验收标准（可测试）

- [ ] 输入问题回车发送 → SSE 流式逐字显示答案
- [ ] 答案渲染完成后下方显示引用来源卡片
- [ ] 来源卡片包含文档名、内容片段、相似度
- [ ] 空答案提示"未找到相关信息"
- [ ] 支持 Shift+Enter 换行，Enter 发送
- [ ] 发送中禁用输入（防重复提交）
- [ ] 从 KB 列表和文档列表可进入对话页
- [ ] TypeScript 类型检查通过
- [ ] 后端 55 个测试仍然通过

## 依赖

- 前置：F3（文档管理页），B6（流式问答 API）
- 技术栈：Vue3 + Element Plus + fetch SSE

## 不做什么（边界，防止范围蔓延）

- 不做多轮对话记忆（无对话历史）
- 不做 Markdown 渲染（纯文本即可）
- 不做点赞/点踩/反馈
- 不做对话历史持久化
- 不做"重新生成"按钮
- 不做"停止生成"按钮
