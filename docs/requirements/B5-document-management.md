# 需求卡片：B5-文档管理 API

## 一句话
查看知识库内的文档列表，删除指定文档（级联删除切片+向量）。

## 子块

| 子块 | 功能 | 说明 |
|------|------|------|
| B5-1 | 文档列表 `GET /api/kbs/{id}/documents` | 返回该知识库下所有文档（含状态/切片数） |
| B5-2 | 文档删除 `DELETE /api/documents/{id}` | 级联删除元数据+切片+向量 |

## 验收标准（可测试）

- [ ] 列表返回知识库内所有文档
- [ ] 列表只返回当前用户的库的文档
- [ ] 删除文档返回确认，级联清理切片+向量
- [ ] 删除别人的文档返回 403
- [ ] 删除不存在的文档返回 404
- [ ] `pytest` 全部通过

## 依赖

- 前置：B4（文档上传），复用 `IngestionPipeline.delete_document`
- 权限：复用 `_get_user_kb_or_403`
