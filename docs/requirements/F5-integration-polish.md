# 需求卡片：F5-整体联调与打磨

## 一句话
联调前后端全链路，修补缺漏，打磨 UI 细节，确保 V1 可演示。

## 子块

| 子块 | 功能 | 说明 |
|------|------|------|
| F5-1 | 404 页面 | 已登录用户访问不存在路由显示 404 页 |
| F5-2 | 面包屑导航 | DocList/Chat 显示 KB 名称（调用 API） |
| F5-3 | 全局 loading | 页面切换时有过渡提示 |
| F5-4 | 错误态兜底 | 网络断开/超时的友好提示 |
| F5-5 | 视觉打磨 | 间距/颜色/阴影一致性 |
