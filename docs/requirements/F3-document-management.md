# 需求卡片：F3-文档上传与管理页

## 一句话
进入知识库后，可以上传文档（PDF/TXT/MD）、查看文档列表与状态、删除文档。

## 子块

| 子块 | 功能 | 说明 |
|------|------|------|
| F3-1 | 文档列表页 | `/kbs/:kbId/docs` — 表格展示文档（文件名/类型/状态/切片数/时间） |
| F3-2 | 文档上传 | 选择文件 → `POST /api/kbs/{id}/documents` multipart → 刷新列表 |
| F3-3 | 文档删除 | 二次确认 → `DELETE /api/documents/{id}` → 刷新列表 |
| F3-4 | 知识库详情入口 | KB 卡片"查看文档"按钮链接到文档页 |

## 输入 / 输出

- 列表页：`GET /api/kbs/{id}/documents` → 表格
- 上传：`<input type="file">` → multipart POST → 自动刷新
- 删除：确认框 → DELETE → 刷新列表
- 支持格式：.pdf, .docx, .md, .txt（前端校验 + 后端校验）

- [ ] 后端 55 个测试仍然通过

## 依赖

- 前置：F2（KB 管理页 + DefaultLayout），B4（文档上传 API），B5（文档列表/删除 API）
- 技术栈：Vue3 + Element Plus + axios

## 不做什么（边界，防止范围蔓延）

- 不做文档预览/在线查看
- 不做批量上传
- 不做拖拽上传
- 不做上传进度条
- 不做状态刷新轮询（手动刷新即可）
